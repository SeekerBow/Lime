# lime.ui — 主窗口与对话框

把各模块组装为完整应用。

## `MainWindow(QMainWindow)`

布局（上下两个 `QSplitter`）：

```
┌──────────┬────────────────────────┬───────────┐
│ 文件浏览器 │ 查找替换条（可隐藏）     │ AI 侧边栏  │
│          │ 多标签编辑器            │           │
├──────────┴────────────────────────┴───────────┤
│ 运行输出 / 集成终端（QTabWidget，可隐藏）        │
└───────────────────────────────────────────────┘
```

- 菜单：文件（新建/打开/保存/另存/最近打开/退出）、编辑
  （撤销/重做/查找/替换）、运行（F5/停止）、终端（重启/清空）、
  视图（三个面板开关）、设置、帮助；
- 打开文件支持多选，过滤器包含所有可运行扩展名；
- 运行未保存文档时先引导保存；不支持的扩展名在状态栏提示；
- 切换标签时自动重绑光标/文本信号：状态栏行列位置、
  AI 上下文（文件名/全文/选中）随动；
- 关闭窗口时逐个确认未保存文档，保存窗口几何/状态并终止终端。

## `SettingsDialog(QDialog)`

表单编辑：字体、字号、Tab 宽度、空格替代 Tab、行号、自动换行、
高亮样式（Pygments 全部内置样式）、Ollama 地址/模型/超时、终端 Shell。
确定后写回 `Settings`，主窗口即时刷新编辑器与 AI 客户端。

## 测试

`tests/test_main_window.py`：初始标签、快捷键注册、文件浏览器信号联动、
查找条、视图开关、光标状态、未保存运行拦截、关闭确认三路径与
几何持久化、最近文件追踪。
